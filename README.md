## Website files

This is a static HTML, CSS and JavaScript website. No build or installation is needed. Serve this repository root using any static web server. Asset paths are relative so the page also works below a repository subpath.

The enquiry form opens a prefilled WhatsApp chat. Customers review and send the message themselves. There is no backend or customer-data database.

Canonical links and the sitemap point to the primary Netlify website. Keep the public Google verification meta tag when updating that website. Repository source is based on commit `40950a2d6ab045863cc0b6f74bbad1aac7232ca3` of the existing website source.
